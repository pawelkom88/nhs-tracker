# Derived Figures are exact sums only; never estimates

Some nations publish counts only as bands (e.g. Scotland's ongoing waits have no single "over 52 weeks" column, only bands from 52 weeks upward). We allow Derived Figures that exactly add Official Figures from the same release, labelled as calculated by us with sources, because they are lossless and checkable. We never estimate: no interpolating medians or percentiles from bands, no filling gaps, no approximating another nation's definitions, even when it would make pages look more complete.

## Consequences

- A Derived Figure inherits any quality flag on its inputs; if any input is suppressed or missing, the Derived Figure is not shown.
